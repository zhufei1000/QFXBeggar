QFXBeggar / 乞讨者 1.0.25

核心功能
- 在暴雪冒险指南原生掉落列表中添加绿色关注星标。
- 选择关注品质后才真正加入关注列表。
- 关注列表按“大秘境 / 团队副本”分类；大秘境按副本分组，团队副本按首领分组。
- 大秘境自动密语分为两条独立规则：
  1) 关注装备：达到关注品质即自动索要，不比较当前装备装等。
  2) 装等提升：装备适合当前专精或拾取专精，且实际装等高于对应已装备槽位时自动索要。
- 团队副本：
  - 关注装备达到关注品质时，可选择自动发送团队专用密语。
  - 非关注装备不会自动密语，但ROLL结束后仍显示“索要”按钮供玩家手动发送。
- 大秘境 / 团队副本拥有独立密语模板。
- “自动密语”面板可独立开关：大秘境关注、大秘境装等提升、团队副本关注三条规则。
- 自己获得、ROLL币获得或交易收到达到关注品质的装备后自动取消关注。
- 战团绑定/账号绑定/Warbound until equipped 等额外个人奖励永远不进入自动乞讨。
- Bonus Roll / ROLL币及 pushed/secondary 类型的额外奖励不进入队友自动乞讨。
- 对无法合法读取的 Secret Value 采取保守策略，不绕过限制。

界面
- 关注列表顶部“乞讨规则”可查看当前索要逻辑说明。
- 底部“密语设置”管理两套密语模板。
- 底部“自动密语”管理三条独立自动规则。

命令
/beggar
/qfxbeggar
/beggar on   开启全部自动密语规则
/beggar off  关闭全部自动密语规则
/beggar help
